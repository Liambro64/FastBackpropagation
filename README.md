<h1>Fast Backpropagation</h1>
This is a "fast" backpropagation algorithm that I am creating to enchance my knowledge of simple AI and refine + expand upon my current knowledge of coding

<h2>How is it being Trained?</h2>
Currently it uses a simple backpropagation algorithm, and a NetworkTrainer class that lets you input a format input and format output that uses data from a file you have loaded and parsed with a specified function.
I am currently in the proccess of learning and using cURL and an API to train it off real-time stock data. 

<h2>What state is this project currently in?</h2>
**This is in a very early stage of development** and I am still even working on adding GPU functions.
